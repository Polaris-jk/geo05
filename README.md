# Lodestar — สมุดสนามดิจิทัลของนักศึกษาเทคโนโลยีธรณี มข. (v0.5)

(ชื่อเดิม GEO) Lodestar คือดาวนำทางหรือดาวเหนือ (Polaris) ส่วน lodestone คือแมกนีไทต์ หินแม่เหล็กธรรมชาติที่ใช้ทำเข็มทิศอันแรก

เว็บแอป (PWA) สำหรับออกภาคสนาม ใช้ได้ทั้ง iPhone และ Android ไม่มีค่าใช้จ่าย ไม่ต้อง login
ข้อมูลทั้งหมดเก็บในเครื่องผู้ใช้ และใช้งานได้แม้ไม่มีสัญญาณ

## เปลี่ยนแปลงใน v0.5

- **กล้องในแอป** (หน้า Station → ถ่ายรูป): ขณะถ่ายเห็นแถบเข็มทิศ ทิศที่กล้องหันไป (เช่น 127° SE) มุมเงย/ก้ม กากบาทกลางจอ และแถบ Smart Photo (Station ชนิดหิน Grid Ref) ทิศถูกบันทึก ณ วินาทีที่กดชัตเตอร์ ถือมือถือแนวนอนก็ได้ แอปหมุนรูปให้ตั้งตรง
  - ภาพจากกล้องในแอปละเอียดระดับวิดีโอ (ราว 1080p–4K แล้วแต่เครื่อง) ถ้าต้องการภาพละเอียดสูงสุด แตะ **กล้องปกติ** ในหน้ากล้อง
- **เปิดดูรูปเป็น Smart Photo ก่อน** แตะ **รูปเดิม** เพื่อดูต้นฉบับ (เปลี่ยนค่าเริ่มต้นได้ที่ Settings → Smart Photo)
- **ทิศที่ถ่ายตัวใหญ่** ใน Smart Photo อยู่บรรทัดเดียวกับ Grid Ref
- **หน้า GPS พอดีจอ** ไม่เลื่อนขึ้นลง แผนที่ย่อ/ขยายตามขนาดจอ
- **ไอคอนใหม่** ดาวเข็มทิศ (icons/lodestar.svg)

## เปลี่ยนแปลงใน v0.4

- **วัด Strike/Dip ด้วยเซนเซอร์:** วางหลังมือถือแนบผิวชั้นหิน ถือนิ่ง 1.5 วินาที แอปล็อกค่าเอง (สั่นและมีเสียง) แล้วบันทึกลง Station ได้ทันที วัดต่อกันหลายค่าได้
- **ปรับศูนย์เซนเซอร์** (Settings, ไม่บังคับ) แก้ค่าเอียงจากกล้องหลังที่นูนหรือเคส
- เปลี่ยนชื่อแอปเป็น **Lodestar** (ลิงก์ GitHub `/geo/` และข้อมูลในเครื่องเหมือนเดิม)
- **Smart Photo:** รูปพร้อมแถบข้อมูลต่อท้ายใต้ภาพ (ไม่ทับรูป) มี Station ชนิดหิน Grid Ref, UTM, Lat/Long ความสูง ทิศที่ถ่าย Strike/Dip วันเวลา เก็บไว้ในแอปทุกรูป และบันทึกลงเครื่องอัตโนมัติเมื่อกด SAVE STATION (Android) รูปต้นฉบับไม่ถูกแก้
- **ทิศที่ถ่ายรูป (Bearing):** อ่านให้เองตอนกด ถ่ายรูป ใช้ทิศจากกล้อง (EXIF) ถ้ามี และตั้งใหม่ได้โดยเล็งมือถือ
- **Grid Reference 6 หลักเป็นพิกัดหลัก** (เช่น 688 189 ในจัตุรัส 48Q TD) สำหรับปักบนแผนที่ 1:50,000 Easting/Northing ย่อลงเป็นบรรทัดรอง
- Export: เพิ่ม Smart Photos (ZIP) คอลัมน์ grid_ref, mgrs, method (sensor/manual) และทิศที่ถ่ายใน photos.csv

## เปลี่ยนแปลงใน v0.3

- แตะ Station แล้วเปิดเป็นหน้า**อ่านอย่างเดียว** ต้องกด **แก้ไข** ก่อนจึงจะแก้หรือลบได้ กันมือลั่น
- ปัดรายการ Station ไปทางซ้าย เจอปุ่ม **แก้ไข** และ **ลบ**
- **แผนที่สรุปโปรเจกต์** เป็นรูปแนวตั้งสำหรับ IG มีเส้นเชื่อมทุก Station เวลาที่บันทึกแต่ละจุด และเวลารวมจากจุดแรกถึงจุดสุดท้าย
- ปุ่ม **EXPORT** เลือกได้ว่าจะส่งออกโปรเจกต์ไหน และรูปแบบไหน เพิ่ม Excel, KML, GPX
- ตัวเลือกหินเหลือเฉพาะหินที่พบในจังหวัดขอนแก่น ตัดตะกอน Qa, Qt ออก
- แผนที่ในแอปมีเส้นเชื่อม Station ตามลำดับเวลา
- **แก้บั๊ก:** v0.1–v0.2 วาดสัญลักษณ์ Station บนแท็บ Map เลื่อนลงจากตำแหน่งจริง (ยิ่ง Station หลัง ๆ ยิ่งเลื่อนมาก) พิกัดที่บันทึกและไฟล์ export ถูกต้องมาตลอด ผิดเฉพาะการแสดงบนแผนที่ในแอป

## มีอะไรในเวอร์ชันนี้

| หน้า | ทำอะไรได้ |
|---|---|
| **GPS** | Grid Ref 6 หลักตัวใหญ่ (พร้อมรหัส 48Q TD) Easting/Northing ตัวเล็กใต้, Accuracy, Altitude สลับเป็น Lat/Long ได้, ปุ่มคัดลอกพิกัด, Bearing จากเข็มทิศ |
| **New Station** | เปิด GPS ครั้งเดียวเพื่อปักพิกัด แล้วปิดเอง, เฉลี่ยพิกัด 10 วินาที, ชนิดหิน (พิมพ์เองหรือแตะตัวเลือกหินที่พบในจังหวัดขอนแก่น), Weathering W1–W6, สี, Strike / Dip / Dip direction ตาม right-hand rule (วัดด้วยเซนเซอร์หรือกรอกเอง), หลายการวัดต่อ Station, Sample ID อัตโนมัติ, รูปภาพ, Notes |
| **Projects** | แยกข้อมูลเป็นหลายโปรเจกต์ (เช่น หนึ่งวันหรือหนึ่งไลน์เดิน) สร้าง สลับ แก้ชื่อ และลบได้ แต่ละโปรเจกต์มีรหัสตัวอย่างหินของตัวเอง แอปเตือนถ้ารหัสซ้ำ |
| **Stations** | รายการ Station ของโปรเจกต์ที่ใช้อยู่ แตะเพื่อ**อ่านอย่างเดียว** ปัดรายการไปทางซ้ายเพื่อ แก้ไข หรือ ลบ, ปุ่มแผนที่สรุป และปุ่ม Export |
| **หน้า Station** | เปิดมาเป็นหน้าอ่านอย่างเดียว (พิกัด หิน โครงสร้าง ตัวอย่าง รูป บันทึก) แตะรูปเพื่อดูเต็มจอ ปุ่มถัดไป/ก่อนหน้า ต้องกด **แก้ไข** มุมขวาบนก่อนจึงจะแก้ได้ |
| **Map** | ทุก Station แสดงเป็นสัญลักษณ์ strike/dip แบบแผนที่ธรณี มีเส้นเชื่อมตามลำดับเวลาที่บันทึก ปุ่มตำแหน่งเปิด GPS ครั้งเดียว ปุ่มรูปภาพไปหน้าแผนที่สรุป |
| **แผนที่สรุป** | รูปแนวตั้งสำหรับลง IG (โพสต์ 4:5 หรือสตอรี่ 9:16) มีทุก Station เส้นทางตามลำดับ เวลาที่บันทึกแต่ละจุด เวลารวม ระยะทาง กริด UTM ทิศเหนือ และมาตราส่วน |
| **Settings** | ชื่อและรหัสของโปรเจกต์, ผู้เก็บข้อมูล, รูปแบบพิกัด, ล็อก UTM โซน 47/48, magnetic declination, ความแม่นยำที่ให้ GPS ปิดเอง, ปรับศูนย์เซนเซอร์วัดชั้นหิน, วิธีลดการถามสิทธิ์, โหมดมืด/กลางแดด |

ทุกการแก้ไขในหน้า Station บันทึกลงเครื่องทันที แม้แบตหมดหรือแอปปิดกลางคัน ข้อมูลที่กรอกแล้วก็ไม่หาย

### GPS แบบแตะครั้งเดียว

Lodestar ไม่เปิด GPS ค้างไว้เลย
- **ดูตำแหน่ง** เปิด GPS หาพิกัดปัจจุบัน แล้วปิดเองเมื่อได้ความแม่นยำตามที่ตั้งไว้ (ค่าเริ่มต้น ±5 m) หรือครบ 30 วินาที แตะ **ใช้ค่านี้** เพื่อหยุดก่อนได้
- **NEW STATION** สร้าง Station แล้วเปิด GPS ปักพิกัดของ Station นั้นแบบเดียวกัน
- พิกัดล่าสุดถูกจำไว้ เปิดแอปครั้งต่อไปจะเห็นค่าเดิมพร้อมเวลา โดยไม่ต้องเปิด GPS

### Grid Reference 6 หลัก

- อ่านแบบเดียวกับแผนที่: 3 หลักแรกคือ Easting 3 หลักหลังคือ Northing ในจัตุรัส 100 km (ตัวอักษรเช่น 48Q TD พิมพ์ไว้ขอบระวาง) ตัดเศษเป็นช่องละ 100 m
- คำนวณบน WGS84 ตรงกับแผนที่ภูมิประเทศ 1:50,000 ที่นักศึกษาใช้ (WGS84)
- ไฟล์ export มีคอลัมน์ `grid_ref` (เช่น 688 189) และ `mgrs` (ละเอียด 1 m เช่น 48QTD6885318979)

### วัด Strike/Dip ด้วยเซนเซอร์

1. หน้า Station → Structure → **วัดด้วยเซนเซอร์** (iPhone จะถามสิทธิ์เซนเซอร์ แตะอนุญาต)
2. เลือกชนิดโครงสร้างด้านบน (Bedding, Joint, Fault …)
3. วาง**หลังมือถือ**แนบกับผิวชั้นหิน หน้าจอหงายขึ้น ถือนิ่ง ๆ แถบจะเต็มใน 1.5 วินาทีแล้วล็อกค่าเอง (สั่นและมีเสียง) หรือแตะ **ล็อกค่านี้**
4. **บันทึกค่านี้** หรือ **บันทึก แล้ววัดต่อ** (ยกไปวางบนระนาบถัดไป แอปจะไม่ล็อกค่าเดิมซ้ำ)

- ปุ่มเซนเซอร์ท้ายแถวการวัด ใช้วัดค่าแถวนั้นใหม่ ถ้าพิมพ์แก้ค่าเอง แถวนั้นจะถือเป็นค่ากรอกเอง
- ทิศอ้างทิศเหนือตาม Magnetic declination ใน Settings (0 = ทิศเหนือแม่เหล็กแบบ Brunton)
- **ปรับศูนย์ (ไม่บังคับ แต่แนะนำ):** Settings → เซนเซอร์วัดชั้นหิน → ปรับศูนย์ วางมือถือบนโต๊ะ รอให้อ่านค่า แล้วหมุนกลับหัว 180° วางที่เดิม ทำใหม่เมื่อเปลี่ยนเคส
- ผิวหินขรุขระหรือชั้นเอียงน้อย ให้วางบนสมุดหรือแผ่นแข็งที่แนบผิวชั้น เพื่อเฉลี่ยความขรุขระ
- อยู่ห่างค้อนและเหล็ก ถ้าแอปเตือนว่าเข็มทิศคลาดเคลื่อน ให้หมุนมือถือเป็นเลข 8 แล้ววัดใหม่ ค่าสำคัญควรเทียบกับเข็มทิศธรณี

### Smart Photo และทิศที่ถ่าย

- **ถ่ายรูป** เปิดกล้องในแอป ทิศบันทึก ณ ตอนกดชัตเตอร์ ถ้าใช้ **กล้องปกติ** ทิศอ่านตอนแตะปุ่ม (แสดงเป็น ≈) และถ้ารูปมีทิศใน EXIF จะใช้ค่านั้นแทน
- ในหน้าแก้ไข แตะรูป → **ทิศ** แล้วเล็งหลังมือถือไปที่ outcrop ในมุมเดียวกับตอนถ่าย → **ใช้ทิศนี้**
- ทุกรูปมี Smart Photo เก็บไว้ในแอป (วาดใหม่ให้เองเมื่อข้อมูล Station เปลี่ยน)
- กด **SAVE STATION** แล้ว Smart Photo ของรูปใหม่จะบันทึกลงเครื่องเอง: Android อยู่ในโฟลเดอร์ Download (เห็นในแกลเลอรี) ปิดได้ใน Settings → Smart Photo
- iPhone: เว็บแอปบันทึกรูปลงเครื่องเองไม่ได้ (iOS ต้องให้แตะยืนยัน) ให้แตะรูป → **Smart Photo** → **บันทึกหรือแชร์** → Save Image
- แตะรูป → **Smart Photo** → **บันทึกหรือแชร์** ส่งเข้า LINE หรือใส่รายงานได้เลย
- ทำทั้งโปรเจกต์ทีเดียว: EXPORT → **Smart Photos**

### เวลาที่บันทึก

เวลาของแต่ละ Station คือเวลาที่กด **NEW STATION** การเข้าไปแก้ไขภายหลังไม่เปลี่ยนเวลานี้ (เวลาแก้ไขล่าสุดแสดงแยกไว้ท้ายหน้า Station)
แผนที่สรุปนับเวลารวมจาก Station แรกถึง Station สุดท้ายตามเวลานี้

### แผนที่สรุป (รูปสำหรับ IG)

หน้า Stations → **แผนที่สรุปโปรเจกต์** (หรือปุ่มรูปภาพในหน้า Map)
- **ขนาดรูป:** โพสต์ 4:5 (1080×1350) หรือสตอรี่ 9:16 (1080×1920 เว้นขอบบนล่างไว้ให้แถบของ IG)
- **พื้นหลัง:** แผนที่ OpenStreetMap (ต้องมีเน็ต) หรือพื้นเรียบ
- **สี:** มืด หรือ สว่าง
- **หมุนได้:** แอปหมุนแผนที่ให้เส้นทางเต็มกรอบแนวตั้ง ลูกศรทิศเหนือชี้ทิศจริงเสมอ เลือก **ทิศเหนือขึ้นเสมอ** ถ้าไม่ต้องการให้หมุน
- กด **บันทึกหรือแชร์รูป** แล้วเลือก Instagram หรือบันทึกลงอัลบั้ม
- ถ้าใช้พื้นหลังแผนที่ ให้คงเครดิต © OpenStreetMap contributors ไว้ในรูปตามเงื่อนไขของข้อมูล

### Export

แตะ **EXPORT** ในหน้า Stations แล้ว
1. เลือกโปรเจกต์ (เลือกได้หลายโปรเจกต์ หรือ **เลือกทั้งหมด**)
2. เลือกรูปแบบไฟล์

| รูปแบบ | ใช้ทำอะไร |
|---|---|
| **Project ZIP** (แนะนำ) | ทุกอย่างในไฟล์เดียว: Excel, CSV, GeoJSON, KML, GPX, รูปภาพ และ `project.json` สำรองข้อมูล ถ้าเลือกหลายโปรเจกต์ จะแยกโฟลเดอร์ละโปรเจกต์ |
| **Excel (.xlsx)** | แผ่นงาน Stations, Structures, Samples หัวตารางล็อกไว้และกรองได้ |
| **CSV** | ตาราง Stations สำหรับ Google Sheets หรือโปรแกรมอื่น |
| **GeoJSON Stations** | จุด Station สำหรับ QGIS / ArcGIS |
| **GeoJSON Structures** | หนึ่งจุดต่อหนึ่งการวัด ใช้ทำสัญลักษณ์ strike/dip |
| **KML** | เปิดใน Google Earth พร้อมเส้นทางตามลำดับเวลา |
| **GPX** | จุดและเส้นทางสำหรับแอป GPS อื่น ๆ |
| **Smart Photos** | ทุกรูปพร้อมแถบข้อมูล Station (ZIP) |

- ไฟล์ export มีทั้ง UTM และ Lat/Long เสมอ ไม่ว่าหน้าจอจะแสดงแบบไหน และมีคอลัมน์ `project` บอกว่าแต่ละแถวมาจากโปรเจกต์ไหน
- วันที่และเวลาในไฟล์คือเวลาที่บันทึก Station (ตอนกด NEW STATION)
- CSV เป็น UTF-8 แบบมี BOM ภาษาไทยจึงแสดงถูกต้องใน Excel

## สิทธิ์ GPS และเข็มทิศ

Lodestar ไม่ขอสิทธิ์อะไรตอนเปิดแอป จะถามเฉพาะตอนแตะปุ่มที่ต้องใช้ GPS หรือเข็มทิศ

- **Android:** Chrome จำสิทธิ์ตำแหน่งไว้ และเข็มทิศไม่ต้องขอสิทธิ์
- **iPhone:** iOS เป็นคนกำหนดว่าจะถามซ้ำบ่อยแค่ไหนสำหรับเว็บแอป ลดการถามได้โดย
  1. Settings → Privacy & Security → Location Services → Safari Websites → While Using the App
  2. Settings → Apps → Safari → Location → Allow (iOS 17 ลงไปอยู่ที่ Settings → Safari → Location)

  เข็มทิศบน iPhone ต้องแตะอนุญาตใหม่ทุกครั้งที่เปิดแอป เป็นข้อจำกัดของเว็บแอปบน iOS ที่แก้จากฝั่งแอปไม่ได้ แอป APK บน Android จะไม่มีปัญหานี้

## ขึ้น GitHub Pages ฟรี เพื่อใช้บนมือถือ

GPS และเซนเซอร์ใช้ได้เฉพาะเว็บที่เปิดผ่าน https ซึ่ง GitHub Pages ให้มาฟรี

1. สร้าง repository ใหม่ใน GitHub ชื่อ `geo` แบบ **Public**
2. แตก zip ก่อน (คลิกขวา → Extract All) แล้วเปิดโฟลเดอร์ `geo`
3. ในหน้า repo กด **Add file → Upload files** แล้ว**ลาก**ทุกอย่างข้างในโฟลเดอร์ `geo` (ทั้งไฟล์และโฟลเดอร์ css, fonts, icons, js, vendor) มาวาง ห้ามใช้ปุ่ม choose your files เพราะเลือกโฟลเดอร์ไม่ได้
4. รอจนรายการไฟล์ขึ้นครบ แล้วกด **Commit changes**
5. ไปที่ **Settings → Pages** ตั้ง Source เป็น **Deploy from a branch**, Branch เป็น `main` และ `/ (root)` แล้วกด **Save**
6. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/geo/`

### อัปเดตเป็นเวอร์ชันใหม่

ทำขั้นที่ 2–4 ซ้ำกับไฟล์เวอร์ชันใหม่ GitHub จะเขียนทับไฟล์เดิมให้เอง ข้อมูลที่บันทึกไว้ในมือถือยังอยู่ครบ เพราะเก็บในเครื่อง ไม่ได้อยู่บน GitHub
เปิดแอปในมือถือหลังอัปเดต แล้วปิดและเปิดใหม่อีกครั้ง จะได้เวอร์ชันล่าสุด

ถ้าแก้โค้ดเอง ให้เปลี่ยน `VERSION` ในบรรทัดแรก ๆ ของ `sw.js` ด้วย (เช่น `geo-v0.3.1`) มือถือจึงจะโหลดเวอร์ชันใหม่ ถ้าเพิ่มไฟล์ใหม่ ให้เพิ่มชื่อไฟล์ในรายการ `SHELL` ใน `sw.js`

## ข้อควรรู้ก่อนออกภาคสนาม

- **ข้อมูลอยู่ในเครื่องเท่านั้น** ให้ Export เป็น Project ZIP เก็บไว้หลังออกสนามทุกวัน
- **บน iPhone ถ้าลบไอคอน Lodestar ออกจากหน้าจอโฮม ข้อมูลในแอปจะถูกลบด้วย** และถ้าใช้ผ่าน Safari โดยไม่ติดตั้ง ข้อมูลอาจถูกล้างเมื่อไม่ได้เปิดเกิน 7 วัน
- **แผนที่ offline:** ก่อนออกสนาม เปิดแผนที่บริเวณที่จะไปขณะมีเน็ต เลื่อนดูและซูมระดับที่ต้องใช้ ส่วนที่เคยเปิดจะถูกจำไว้ใช้ตอนไม่มีสัญญาณ
- **Elevation:** iPhone ให้ความสูงจากระดับทะเล ส่วน Android ให้ความสูงจากทรงรี WGS84 ซึ่งในไทยต่างกันราว 10–40 m (ขอนแก่นราว 30 m) Lodestar แปลงค่าของ Android ด้วยแบบจำลอง geoid EGM96 ให้เป็นระดับทะเลแล้ว แต่ความสูงจาก GPS ยังคลาดเคลื่อนได้หลายเมตร
- **เข็มทิศมือถือ:** อยู่ห่างค้อน แม่เหล็ก และหินที่มีแร่แม่เหล็ก ถ้าค่ากระโดด ให้หมุนโทรศัพท์เป็นเลข 8 เพื่อปรับเทียบ ค่าที่สำคัญควรยืนยันด้วย Brunton
- **ลบด้วยการปัด** จะถามยืนยันก่อนทุกครั้ง และลบรูปของ Station นั้นด้วย ลบแล้วกู้คืนไม่ได้

## นำเข้า QGIS

- **GeoJSON:** ลาก `stations.geojson` หรือ `structures.geojson` เข้า QGIS ได้ทันที (EPSG:4326)
- **CSV:** Layer → Add Layer → Add Delimited Text Layer → X = `utm_e`, Y = `utm_n`, CRS ตามคอลัมน์ `utm_epsg` (EPSG:32648 สำหรับโซน 48N) หรือใช้ X = `lon`, Y = `lat` กับ EPSG:4326
- **KML / GPX:** ลากเข้า QGIS ได้เหมือนกัน (มีทั้งจุดและเส้นทาง)
- **สัญลักษณ์ strike:** เปิด `structures.geojson` → Symbology → Simple Marker → Shape: Line → Rotation แบบ data-defined เป็นฟิลด์ `strike` แล้วใส่ Label เป็นฟิลด์ `dip`
